# R122–R129 Staging 整合驗證

比對基底為 r101-template-staging 的 6f0e26c。該提交標示 R120，來源未包含可識別的 R121 提交。兩個 ZIP 全檔依相對路徑及正規化換行後的 SHA-256 比對。舊模板比基底少 6 檔、3 檔有差異、14 檔相同。客戶版比基底多 13 檔、缺 6 檔、10 檔有差異、7 檔相同。

- 沿用客戶版的八支函式、既有測試及三支 SQL 遷移。重新接上通用安裝流程。客戶專案設定與營運封存不進入模板，Threads 帳號改由設定提供。
- 同一資料庫交易寫入 schema、遷移與專案標記。續接時匹配標記，沿用現有資料庫，再更新函式與具名唯讀排程。未標記的非空資料庫會停止。
- Deno 型別檢查、14 個無網路測試、Python／Shell 靜態檢查和 SKILL 格式驗證通過。隔離 PostgreSQL 18 初始化確認三平台發送關閉、歷史留言基準待設定、三筆權杖健康資料與專案標記。

- 此開發工作階段未找到既有 Bot 的安全憑證或可驗證的管理員通訊入口。客戶版現有 Telegram 發送與不確定送達保護保留。開發通知和雙向命令未啟用。
